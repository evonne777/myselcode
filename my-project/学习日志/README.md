# 学习日志

记录我在这个项目里**每次修改代码 / 解决报错 / 请教问题**的过程，方便日后复习。

## 约定

- 目录：项目根目录下的 `学习日志/`
- 文件：每天一个 `YYYY-MM-DD.md`（如 `2026-09-09.md`）
- 记录按 `## 1.`、`## 2.`… 顺序编号，当天新记录追加到当日文件末尾
- 每条记录尽量包含：改了什么、怎么改的、为什么会出错、怎么解决的、运行结果、收获
- 详细模板见：`/root/.codebuddy/skills/learning-log/references/entry-template.md`（或让 CodeBuddy 帮忙写）

## 这套日志怎么自动生效

CodeBuddy 已安装个人 skill：`learning-log`。当你在学习语境下让我改代码、解决报错、提问时，我会在每轮收尾自动往当日日志里追加一条，无需你反复提醒。如果某次没写，直接说“记录一下”即可。
