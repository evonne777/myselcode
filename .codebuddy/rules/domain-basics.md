# 领域基础规则（domain-basics）

> 本文件沉淀“AI 不可能从代码中推断出来”的团队隐性知识。每次会话自动加载。
> 维护方式：每当 AI 犯了一个**信息缺失**类错误（不是能力不足），就补一条。

---

## 一、网络与地址

- `138.x.x.x`、`139.x.x.x` 属于**内网网段**，禁止在任何对外配置（代理、回调地址、CORS 白名单、前端硬编码 baseURL）中当作公网地址使用。
- 涉及 IP 判断、防火墙规则、跨环境地址切换时，必须先确认该地址属于内网还是公网，不得默认按公网处理。

## 二、时间与时区

- **所有入库时间统一使用东八区（UTC+8）**。
- 禁止在写库时使用 UTC 或依赖服务器本地时区；前端展示格式化时也必须显式指定 UTC+8，不得依赖浏览器本地时区。
- 时间戳存储与展示的转换必须集中在一处（如 `src/utils/` 下的工具函数），禁止各页面各写一套。

## 三、接口约定

- 所有 HTTP 请求必须走 `src/utils/request.js` 的 axios 封装，**禁止在业务代码里直接 `import axios`** 或直接调 `fetch`。
- 接口函数统一放在 `src/api/` 下按模块拆分，组件不直接拼 URL 发请求。
- 需要接口数据时优先 `dispatch` Vuex action，而不是在组件里直接调 api 函数（详见 `src/store/modules/`）。
- **新增接口前必须先检查 `src/api/` 下是否已有同 URL 的函数**，避免重复定义（当前 `src/api/user.js` 中 `getInfo` 与 `getUserInfo` 就是重复实现同一接口，属于待清理的历史遗留）。

## 四、前后端联调与 Mock

- `mock/` 目录仅用于**开发环境**，不得进入生产构建产物。
- Mock 数据的响应结构必须与真实接口保持一致，禁止在 mock 里“简化”字段，否则会造成联调期假象。

## 五、代码风格与工程约束

- 项目为 **Vue 2 + webpack 3** 的老技术栈，禁止引入 Vue 3 语法（Composition API、`<script setup>`）或仅支持 Vue 3 的第三方库。
- 语法层面以 `babel-preset-env` + `stage-2` 为准，可用可选链等已配置的语法，但不得使用未配置的提案语法。
- 路径统一使用 `@` 别名（指向 `src`），禁止写多层 `../../../` 相对路径。

## 六、环境与工具链

- Windows 环境下需注意工具链不在 C 盘（路径过深 + 符号链接权限问题）。
- 并行开发使用 `codebuddy --worktree <名称>`，worktree 建在 `.codebuddy/worktrees/` 下，收工需手动清理。
